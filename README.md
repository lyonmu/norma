# Norma

Norma is a cross-platform desktop agent built on GPUI, providing developers and power users with a unified, efficient, and extensible AI workspace.

By integrating multi-model capabilities, the MCP tool ecosystem, a "Skills" plugin system, and multi-agent collaboration mechanisms, Norma enables users to handle a wide range of tasks—from information processing and coding to automated task execution.

## Features

### Multi-Model Support

Supports OpenAI, Anthropic, Gemini, Qwen, DeepSeek, OpenRouter, and other services compatible with the OpenAI API.

Flexibly select the most suitable model for specific task scenarios.

### MCP Protocol Support

Native support for the Model Context Protocol (MCP).

Easily connect to databases, Git repositories, local tools, enterprise knowledge bases, and third-party services to equip the agent with extensive tool capabilities.

### ACP Protocol Support

Supports the Agent Communication Protocol (ACP).

Enables standardized communication, task collaboration, and context sharing between agents.

### Skill Support

Extend agent capabilities via an extensible "Skills" system.

Supports various scenarios such as software development, DevOps, data analysis, security research, and document processing.

### Sub-Agents

Supports the dynamic creation of sub-agents.

Complex tasks can be automatically decomposed and executed in parallel, improving processing efficiency.

### Multi-Agent Collaboration

Supports collaboration among multiple agents.

Different agents can assume roles such as planning, research, development, and review to jointly complete complex tasks.

### Cross-Platform

Built on GPUI, delivering a modern, native desktop experience.

Supported platforms:

- macOS
- Linux
